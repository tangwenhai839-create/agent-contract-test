# Reproducible real-agent runs

This directory contains real coding-agent runs against pinned public repository revisions. Results are published whether the contract passes or fails.

Each run records the contract, agent CLI version, baseline commit, changed files, deterministic verification result, a sanitized machine-readable summary, and the candidate patch. Raw authentication data, private paths, and complete model transcripts are not published.
